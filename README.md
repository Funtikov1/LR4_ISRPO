# ShopLibrary

Лабораторная работа №4 по ИСРПО.
Тема: разработка и интеграция модулей проекта, отладка и обработка исключений.

## Назначение

Библиотека для учёта товаров в магазине.
Реализованы поступление товара, продажа и расчёт стоимости остатка.

## Структура решения

ShopLibrary – библиотека классов:
- Models – класс товара Product.
- Interfaces – интерфейс IProductService.
- Services – класс ProductService.
- Exceptions – собственное исключение InvalidProductException.

ShopLibrary.Tests – проект модульных тестов.
Содержит шесть тестов для проверки операций и обработки исключений.

## Сборка и запуск тестов

1. Установить Visual Studio с компонентами разработки .NET
   и пакетом разработки .NET Framework 4.8.
2. Открыть файл ShopSolution.sln.
3. При необходимости восстановить пакеты NuGet через
   контекстное меню решения.
4. Выбрать «Сборка» → «Собрать решение».
5. Открыть «Тест» → «Обозреватель тестов».
6. Нажать «Запустить все тесты».

Ожидаемый результат – шесть успешно пройденных тестов.
Библиотека проверяется через проект тестов.
